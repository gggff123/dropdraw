# dropdraw
A fun lightweight drawing app , everything happens in the terminal made in pure C and ncurses
> This is a fun begginer freindly project made for windows specifically and has all instructions related to this OS

# How to run it
You can run it easily by downloading the exe from the realeases section or compile the code ``main.c`` yourself.

# Compilation

1) Clone the repo `` git clone https://github.com/gggff123/dropdraw.git ``
2) Compile the main.c file , for msy64 and minigw64 do this ``gcc main.c -o dropdraw.exe``
3) run the application via ``./dropdraw.exe``
4) Enjoy 🐸
